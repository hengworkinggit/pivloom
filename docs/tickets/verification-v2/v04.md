## What to build

用户能恢复和试用已保存可运行候选，显式从它继续开发，同时保留当前accepted与已发布版本。

## Acceptance criteria

- [ ] 只有本人项目内build-passed候选可恢复预览或被选作增量基线；跨账户/跨项目/构建失败均拒绝。
- [ ] API记录明确selected base、expected current与previousPlan，源码和对话一致；无选择仍保持现有默认语义。
- [ ] 工作台提供清楚的候选恢复/继续入口，展示当前候选与accepted区别，刷新重登能还原选定上下文。
- [ ] 选择候选和恢复预览不把它记为accepted，不改变永久发布，不创建伪造通过Check；版本号保持递增。
- [ ] 停止或结束受阻检查后可继续所选候选；旧检查迟到不覆盖新版；恢复仍遵守沙箱容量与清理规则。
- [ ] 真实HTTP/数据库/浏览器验证保存候选→恢复→继续增量→重登，同时保留旧current与published。
