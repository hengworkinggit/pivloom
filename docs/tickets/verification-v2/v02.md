## What to build

生成应用的检查具有明确目标和初态，能忠实执行重复真实输入，并重用旧行为程序。

## Acceptance criteria

- [ ] 结果/表达式/列表等断言作用于明确对象，正确历史文本不造成清空误判，按键文本不能满足错误结果。
- [ ] 独立场景与同场景持久化明确区分；单跑和换序结果一致；刷新持久化仍可验证。
- [ ] 21次真实计算通过有界批次/序列完整表达和执行，不截成6或11次；不靠放宽业务预期通过。
- [ ] 已存在程序的断言极性/范围和语义不被增量静默改写；旧数据可读，缺失程序可有界补齐；坏程序开始前可发现。
- [ ] 当前协调者/Builder 能按契约生成可定位界面与真实程序；有通用表单/列表与状态场景回归。

## Blocked by
