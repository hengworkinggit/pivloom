## What to build

一个视觉或工具故障不丢弃已完成检查，完整生产入口具有统一墙钟预算、正确取消和可诊断结果。

## Acceptance criteria

- [ ] 通过真实 runReview 入口复现并修复 A 完成后视觉异常全量清零；正式 Check 保留已完成结果，只有相应项受阻。
- [ ] 控件解析回退经真实入口调用；未提供初始观察的程序在执行前给明确错误或合法初始化。
- [ ] A/B/C、截图、模型请求及收尾共享 deadline；取消和版本绑定失效不接受候选；超时保留可信分项但不记成功。
- [ ] 计时与调用用量如实记录；工具预算同时考虑整轮余额与正常复审，不以加大单项常数宣称根治。
- [ ] 入口级 red-green 测试、相关回归和真实浏览器故障场景通过。

## Blocked by

None (can start immediately).
