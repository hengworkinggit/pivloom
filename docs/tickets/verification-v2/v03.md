## What to build

完整受控浏览器场景在沙箱附近执行，显著减少逐键远程往返，同时保留动作、作用域及来源约束。

## Acceptance criteria

- [ ] 批量执行集成进生产 Review 路径，支持读取观察、真实输入、断言、必要截图及失败定位；不是仅新增未接入helper。
- [ ] 模型不逐步驱动可确定执行的操作；原有来源隔离、取消、版本绑定和证据真实性保持。
- [ ] 同一源码与相同检查场景的命令数/总墙钟基准可复跑；不能仅用0模型调用声称快。
- [ ] 真实浏览器覆盖计算器状态、表单/列表与动态控件，关键错误仍能抓到，合法实现不误报。
- [ ] 运行前成本与预算报告包含实际步骤/环境开销；不支持或超容量给具体原因，不静默删检查。
